# Which BMP each piece of art loads from. Written by tools/load_sprite.py;
# hand-editable, and read by src/scene/sprites.cpp at launch.
#
# One record per line:
#
#     <key> <file.bmp> [<frame_w> <frame_h>]
#
# `key` is what the code asks for. `file` is a bare filename inside assets/ -
# no paths, the file has to sit in this directory. The frame size is optional
# and only for sheets; it is checked at load, not used to slice anything.
#
# Naming: a filename says WHAT A THING IS, never which revision it is.
# Revisions belong to version control; names are identities. Drafts and
# superseded art live in assets/wip/, which nothing loads.
#
# Deleting a line, or this whole file, is safe: every key falls back to the
# default asset.
#
# To point a key at something new:
#
#     python tools/load_sprite.py player_sheet my_new_sheet.bmp
#
# which validates the BMP, rewrites the line below, and stages the file next to
# the built exe so it takes effect on the next launch with no rebuild.

# --- player ---------------------------------------------------------------
# The frame size here must match FRAME_W/FRAME_H in tools/player_sheet.py.
# main.cpp checks the whole sheet against the compiled animation table and says
# so if they disagree.
